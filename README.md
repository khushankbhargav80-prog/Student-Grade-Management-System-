# Student Grade Management System

## Project Overview
The Student Grade Management System is a simple mini project developed using the C programming language. It is a console-based application designed to manage student records and calculate their academic performance.

## Features

- Add new student records.
- Store student roll numbers and names.
- Enter marks for five subjects.
- Calculate total marks automatically.
- Calculate average percentage.
- Assign grades based on average marks.
- Display all student records.
- Search students using roll numbers.
- Display the total number of students.

## How to Run the Project

### Step 1: Clone the Repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### Step 2: Open the Project Folder

```bash
cd Student-Grade-Management-System
```

### Step 3: Compile the C Program

```bash
gcc main.c -o student
```

### Step 4: Run the Program

For Windows:

```bash
student.exe
```

For Linux:

```bash
./student
```

## Limitations

- Maximum 100 student records can be stored.
- Records are stored temporarily in memory.
- Data is lost when the program is closed.
- No update or delete option is available.
